# Отчет: приходи, разходи, оборот

Локална програма, която взема продажбите от Microinvest Склад Про и ги показва
по дни заедно с ръчно въведените разходи.

## Стартиране

Нужен е Node.js 18 или по-нов. Не се инсталират допълнителни пакети.

    npm start        # работа с Microinvest
    npm run demo     # демо с примерни данни, без Microinvest

Отворете http://localhost:3000.

## Първоначална настройка

1. В Microinvest Utility Center включете модула **Microinvest API** и отворете порт 8700 в защитната стена.
2. В програмата отидете на **Настройки**, въведете адреса (напр. `http://192.168.1.20:8700`) и ключа, ако има такъв, и натиснете „Запази и провери връзката“.
3. В същия раздел свържете групите артикули от Microinvest с колоните в Приходи (Сервиз, Прима карти, Телефони…). Продажбите от несвързани групи отиват в колоната по подразбиране (Стока).

## Данни

Всичко се пази във файла `data.json` до `server.js`: разходите, ръчните корекции на
приходите, колоните, настройките и копие на продажбите по дни. Правете копие на този файл.

Продажбите се изтеглят веднъж и се пазят локално; последните 3 дни се обновяват при всяко
зареждане. „Обнови от Microinvest“ изтегля наново целия показан период.
